## 3. 제품 — GRank 5종

| # | 솔루션 | 역할 |
|---|---|---|
| 1 | **Scanner** | 무료 진단. URL+이메일 → 2분 → 7개 항목 0~100점 + 경쟁사 2~3곳 비교 + 즉시 개선 3건 |
| 2 | **Research** | 자사·경쟁사 4곳의 AI 노출·후기·평판 다층 리서치 → FACT DB |
| 3 | **QueryMix** | 상위 키워드 → 검색 트리거 → 하위 키워드 3계층 질의 설계 |
| 4 | **Creator** | AI Citability 검사 내장 콘텐츠 제작. 스키마·meta·JSON-LD 자동 |
| 5 | **Pilot** | 실시간 인용 모니터링 (특허 출원 중). 대행료에 포함, 별도 사용료 없음 |

### Scanner 7개 검사 항목 (우리가 만들 무료 진단의 벤치마크)
1. AI 인용 가능성 — 콘텐츠 구조, 질문-답변 패턴, 인용 가능 단락 존재
2. 브랜드 권위 신호 — 외부 언급, 언론, 위키피디아·지식패널 등재
3. E-E-A-T 수준
4. **AI 크롤러 접근성 — GPTBot·ClaudeBot·PerplexityBot 허용, llms.txt·robots.txt**
5. 구조화 데이터 완성도 — Schema.org JSON-LD, 엔티티 구조화
6. 콘텐츠 AI 친화도 — FAQ·HowTo·비교 콘텐츠 패턴
7. 경쟁사 비교 — 동종 2~3곳 항목별 상대 점수

> 우선순위 로직: **기술 항목(크롤러 접근·스키마)이 콘텐츠보다 선행**

### Pilot 대시보드
- 지표 4종: 브랜드 인용률 / AI SOV / 감성·문맥 / 추천 순위
- 화면: 질의별 인용률, 경쟁사 비교판, 플랫폼별 성과, 주차별 추이
- 알림: **카카오·슬랙·SMS** — 인용 이탈, 경쟁사 급상승, 리드 변화
- 경쟁사 3~5개 상시 자동 추적
- 갱신: 인용률 매일 / 경쟁사 변화 매주 / 성과 정리 월간
- **원문 보관 있음** — "인용된 URL과 문장, 어떤 모델이 어떤 출처를 근거로 삼았는지가 함께 남습니다"
- 고객 직접 조작 제한적. 질의 추가는 상담 경유. 계약 전 화면 시연

## 4. 측정 방법론 — 전부 공개돼 있음

```
4개 LLM (ChatGPT·Gemini·Claude·Perplexity)
× 하루 5회 반복 질의
× 매번 새 세션 (개인화 배제)
× 상위 Top5 인용만 인정
```

**위치 가중치** (본인들이 "예시이며 실제 계수는 플랫폼·업종에 따라 조정"이라고 명시)

| 위치 | 가중 |
|---|---|
| 서두 첫 인용 | 1.0 |
| Top3 이내 | 0.7 |
| Top5 이내 | 0.4 |
| Top5 밖 | 0 (미인정) |

**지표 정의**
- 인용률 = 같은 질문 반복 시 브랜드가 인용된 비율 (0~100 정규화)
- AI SOV = 답변 등장 브랜드 중 우리 지분
- 추천 순위 = 답변 내 몇 번째로 인용됐는지
- GVI = 4개 LLM 인용 데이터를 0~100으로 표준화한 가시성 지표

**스스로 인정하는 한계**: "생성형 AI는 같은 질문에도 매번 다른 답" → 한 번의 응답은 표본일 뿐

**⚠ 빠져 있는 것: 신뢰구간·오차범위·표본 수 표기.** 하루 5회면 일간 표본 n=5이고
그 신뢰구간은 ±40%p대인데, 대시보드는 "92%", "1.1위" 같은 단일값으로 표시.
**이것이 현재 유일하게 남은 빈틈.**

## 11. 우리에게 남은 것 / 무너진 것

### 무너진 차별화 축
| 우리가 잡았던 축 | 실제 |
|---|---|
| "방법론을 공개하는 곳이 없다" | **가중치 표까지 공개.** 완전히 무너짐 |
| "반복 측정을 안 한다" | 하루 5회 × 새 세션. 우리 계획보다 촘촘 |
| "답변 원문을 안 보여준다" | Pilot에 인용 URL·문장·모델 보관 |
| "한국어 소스 생태계" | 네이버 Yeti 허용, 지역 엔티티, 네이버 지도 연동까지 함 |
| "측정→실행→재측정 루프" | 주간 5단계 사이클로 이미 운영 |
