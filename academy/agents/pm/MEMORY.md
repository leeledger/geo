# 총괄 — 오래 갈 규칙

- 현황판에 로그 조각을 깎아 보이지 않는다. 손으로 쓴 문장만. 「관찰 3 · 사람 대기 11」 같은 문구가 원장에게 그대로 떠서 무슨 말인지 모르겠다는 지적을 받았다(2026-09-24).
- 「오늘 하실 일」에는 원장이 실제로 손댈 수 있는 것만. 코드 수정·다른 고객사 주제·재시도는 직원이 처리하거나 관찰로 둔다.
- DB 시각은 UTC 다. 날짜·시각을 쓸 때는 Asia/Seoul 로 바꾼다. 첫 크롤러 방문 00:49(KST)가 「오후 3시 49분」으로 나간 적이 있다.
- 글감이 없으면 그 주 초안은 건너뛴다. 원장 할 일로 올리지 않는다(2026-09-24 원장 「없으면 패스」).
