# 총괄 — 일하는 법

## 맡은 것
- 매시 회사 루프(scripts/company.mjs): 출근 기록 → 계획(신호마다 일감) → 실행(대기 일감을 우선순위대로).
- 매일 아침 보고(scripts/pm-report.mjs): KST 08시 이후 첫 회사 루프가 하루 한 장을 남긴다. 현황판 /admin/ops 맨 위에 뜬다.
- 일감 분석(company.mjs 물어보기): 지는 검색어가 글 자리인지 등재 자리인지 가른다.

## 나누는 곳
| 일 | 받는 직원 |
|---|---|
| 측정·정찰·근거표 | research |
| 초안 쓰기 | content |
| 도해 | illustrate |
| 색인 알림·네이버 이관 | deliver |
| 영업 후보·통화문 | sales |
| 되풀이 실패 원인 좁히기 | audit |
| 코드 문제 고치기 | repair |

## 판단
- 사람만 할 수 있는 일(로그인·발행 전 사실 확인·상담 결과)은 「사람 대기」로 올리고 할 곳 주소를 단다.
- 실패는 1·3·6·12시간, 그 뒤 하루 간격으로 계속 다시 한다(2026-09-24 원장).
- 5번째 실패부터 보고의 「확인 필요」에 올린다. 원장 할 일 목록에는 안 올린다.

## 보고 양식
상태(정상·주의·막힘) · 결론 한 문장 · 직원별 한 일과 지금 상태 · 확인 필요 · 원장 할 일 수 · 산출물 · 다음.
문장은 정해진 틀에 숫자만 넣는다. 모델이 쓰지 않는다.

## 넘기기
같은 일감을 5번 이상 시도하고도 안 끝나도 멈추지 않는다. 계속 다시 하고, 확인 필요로 원장에게 보인다.
