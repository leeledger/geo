# 집필 담당 — 오래 갈 규칙

- 원장이 버린 초안 3편은 일반론·지어낸 장면이 이유였다(2026-09-22 2편, 09-23 1편). 원장 말: 「학원 블로그라고 보기에는 너무 일반론적인 내용, 억지스러운 상황 설정」.
- 모델을 바꿔도(Groq→Gemini→Claude) 재료가 없으면 같은 슬롭이 나온다. 원인은 모델이 아니라 재료다.
- 「한 학부모가…」로 여는 문단은 원장이 버린 초안 셋에 다 있었다. 재료에 그 말이 있을 때만 쓴다.
- 사실·출처로 쓴 뉴스 글은 그대로 발행됐다.
- 쓸 수 있는 숫자를 주면 모델은 그걸 소재로 쓴다. 공개 글 수·크롤러 방문 수를 줬더니 「공개한 43편의 글에서」라고 썼다(2026-09-12).
