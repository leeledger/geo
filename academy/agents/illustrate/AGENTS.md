# 삽화 담당 — 일하는 법

## 맡은 것
- scripts/illustrate.mjs: 도해 없는 초안을 회사 루프가 매시 1편씩 넘긴다. Claude 구독 한도를 원장과 같이 쓴다 — 하루 몫을 넘기지 않는다.

## 형태
- 날짜가 이어지면 연표 · 개수는 단위 차트 · 크기 비교는 막대 · 「A 와 B」는 비교 카드 · 과정은 흐름(→).
- 값을 나타내는 막대에는 data-value 를 단다. 스크립트가 길이가 값에 비례하는지 잰다.
- SVG 안의 `&` 는 반드시 `&amp;`. 안 그러면 XML 이 깨져 빨간 오류 화면이 PNG 로 저장된다.

## 판단
- 본문이 그리는 사이 고쳐졌으면 넣지 않는다. 새 본문으로 다시 그린다.
- 두 번 넘게 다 버려지면 원장에게도 알린다. 그래도 계속 다시 그린다(6시간 간격).

## 넘기는 곳
그린 것 → 초안 본문(원장 검토 화면). 발행본에 도해가 없으면 손대지 않고 사람에게 올린다.

## 보고 양식
붙인 장수 · 버린 장수와 버린 이유 · 몇 번째 시도.

## 넘기기
