# 글 한 편 내보내기

주 1편이 목표다. 한 번 돌리면 발행까지 끝난다.
**중간에 멈추지 말 것.** 사이트에만 올리고 끝내면 네이버 유입을 통째로 버린다.

## 1. 주제 고르기

`academy/content/topics.json` 에서 아직 안 쓴 것을 고른다.
`slug` 가 비어 있고 그 슬러그의 글이 DB에 없으면 안 쓴 것이다.

고를 때 보는 것:
- **계절** — `season` 이 지금과 맞는가 (학기초·방학전·대회시즌)
- **얇은 갈래** — 「교육관점」이 이 사이트의 중심인데 가장 얇다
- **검색될 말인가** — 학부모가 실제로 치는 말이어야 한다

사용자가 주제를 줬으면 그걸 쓴다. 은행에 없으면 은행에도 추가한다.

## 2. 쓰기

`academy/scripts/seed-post-*.mjs` 하나를 본으로 삼아 새 파일을 만든다.

지켜야 할 것 (CLAUDE.md 에 있는 것 + 이 글의 뼈대):

```
훅        상담에서 들은 질문 그대로
답을 먼저  결론을 뒤로 미루지 않는다. 미루면 정보 채널이 된다
인정      왜 그 질문이 나오는지 인정하고 넘어간다. 바로 반박하면 설교가 된다
본론      겹치는 것 / 안 겹치는 것을 갈라서
말리기    "하지 마셔야 할 것" ← 이 문단이 전문가와 소개꾼을 가른다
마무리    판단 기준을 주고 끝낸다. 학원 홍보로 닫지 않는다
```

**과장하면 바로 들킨다.** 안 겹치는 것을 먼저 말하는 편이 오히려 설득된다.

먼저 초안으로 넣고 사람이 볼 수 있게 한다:
```
cd academy && node scripts/seed-post-<이름>.mjs
```

## 3. 도해

글의 뼈대를 그림으로 옮긴다. 1~3장. 없으면 본문 중간이 빈다.

- `academy/public/blog/<슬러그>/*.svg`
- 팔레트는 사이트 것 — 배경 `#0B0F16`, 앰버 `#F5A623`, 시안 `#3DD6C4`
- **`&` 는 `&amp;`** 로. 안 그러면 XML 이 깨진다
- `aria-label` 에 내용을 적는다. 그림을 못 보는 쪽에도 뜻이 남아야 한다

굽는다 (파싱 오류도 여기서 잡힌다):
```
cd tools && node svg-to-png.mjs ../academy/public/blog/<슬러그> --scale 1
```

글에 `![설명](/blog/<슬러그>/<이름>.svg)` 로 끼운다.

## 4. 사이트 발행

발행 전에 자동 감수를 돌린다. 세션이 손으로 쓴 글도 같다 — 네 관문(출처 원문 대조·AI 티·원장 관점·가림)을 다 통과해야 발행한다.

```
cd academy && node scripts/auto-post.mjs --review <슬러그>
```

「결과: 통과」가 아니면 발행하지 않는다. 걸린 이유를 고치고 다음 날 다시 돌린다(감수는 하루 1회차).
`--dry` 는 결과만 찍고 아무것도 안 쓴다.

```
cd academy && node scripts/seed-post-<이름>.mjs --publish
cd academy && npx vercel deploy --prod --yes
```

배포 뒤 **실제로 열어서 확인한다.** 그림이 다 뜨는지, 가려야 할 것이 안 나오는지.
로그만 보고 넘어가면 틀린다.

## 5. 네이버 이관

```
cd tools && node naver-blog-post.mjs <슬러그>
```

소제목·굵게·구분선·태그가 자동으로 붙는다.
이미 올린 글을 고쳤으면 **새로 올리지 말고** `--update <logNo>` 를 쓴다.
같은 내용이 두 벌 올라가면 서로 갉아먹는다.

## 6. 색인 알림

```
cd academy && node scripts/indexnow.mjs "https://robotncoding.com/blog/<슬러그>"
```

## 7. 주제 은행 갱신 · 커밋

`topics.json` 의 그 주제에 `slug` 를 채운다.

```
git add -A && git commit
gh auth switch --user leeledger   # 계정이 되돌아가 있으면
git pull --rebase -q origin main && git push -q origin main
```
