# 아이로그 — 2차 전달

1차 파일 세 개(sitemap·llms.txt·JSON-LD)는 그대로 올라가 있습니다. 다시 진단하니 **44점 → 75점**입니다.
이번 파일은 세 가지를 풉니다. AI 가 실제로 읽어 가는지 모르는 것, 이름이 겹치는 것, 원장이 묻는 질문이 사이트에 없는 것.

## 올릴 파일

전부 추가·교체라 화면 동작은 바뀌지 않습니다. `app/Faq.tsx` 만 화면에 새 구역이 생깁니다.

```
middleware.ts                  AI 크롤러 방문 기록 (사람 방문에는 아무 일도 안 함)
lib/cited-bots.ts              위 파일이 쓰는 봇 목록
public/7c1e9a4b2f6d8053a1c4e7b9d2f05a68.txt   IndexNow 키 — 새 페이지를 네이버·빙에 바로 알림
public/llms.txt                교체 — 엔티티 정의, 다른 아이로그와 구분, 질문 대응 추가
app/JsonLd.tsx                 교체 — 다른 아이로그와 구분하는 문장 추가
app/Faq.tsx                    새로 — 화면에 보이는 자주 묻는 질문 5개
```

### 1. 크롤러 기록

- `middleware.ts` 와 `lib/cited-bots.ts` 를 올립니다.
  이미 `middleware.ts` 가 있으면 덮지 말고, 파일 안 「기록」 블록만 기존 함수 맨 앞에 옮깁니다.
  Next.js 16 이상이면 파일 이름이 `proxy.ts`, 함수 이름이 `proxy` 입니다.
- Vercel 환경변수에 `CITED_CRAWL_KEY` 를 넣습니다. 값은 따로 드립니다
  (사이티드 쪽: `node academy/scripts/setup-multiclient.mjs --show-key ilog`).
  PowerShell 파이프로 넣으면 값 앞에 BOM 이 붙습니다. 대시보드에 직접 붙여 넣으세요.
- 키가 없으면 아무 일도 하지 않으므로 올려 두고 키를 나중에 넣어도 됩니다.

### 2. 화면 FAQ

`app/page.tsx` 맨 아래, 푸터 위에 두 줄:

```tsx
import Faq from "./Faq";
// ...
<Faq />
```

질문은 이번 AI 측정에서 아이로그가 안 나온 질문 그대로입니다. 답은 지금 홈페이지와 llms.txt 에 적힌 사실만으로 썼습니다.
스타일은 사이트에 맞게 바꾸면 됩니다. 이 구역이 들어가면 「질문형 제목」과 「인용할 만한 문단」 두 칸이 같이 오릅니다.

### 3. 제목과 설명 — `app/layout.tsx` 의 metadata

지금은 제목이 `아이 로그`, 설명이 `부모님과 소통하는 우리 아이 성장 기록, 아이 로그` 입니다.
학부모용 문장이라 프로그램을 고르는 원장이 검색하는 말과 겹치지 않고, 띄어쓰기도 이름과 다릅니다.

```ts
export const metadata = {
  title: "아이로그 — 무료 학원 관리 프로그램 · 카톡 출결 알림 · AI 수업 리포트",
  description:
    "학원 관리 프로그램 아이로그. 등·하원 카카오톡 알림, AI 수업 리포트, 학교별 기출 영어 예상 문제. 관리 기능은 학생 수 제한 없이 평생 무료.",
};
```

## 사람이 해야 하는 일

- **Bing 웹마스터 등록** — Bing 에 아직 색인이 없습니다. ChatGPT 검색은 Bing 색인에 크게 기댑니다.
  구글 서치콘솔에 등록돼 있으면 Bing 웹마스터에서 「서치콘솔에서 가져오기」로 1분이면 됩니다.
- **네이버 서치어드바이저** — 등록 여부를 확인하고, 안 돼 있으면 사이트맵을 제출합니다.

네이버 웹문서에서 이기고 있는 자리는 전부 경쟁 프로그램의 **자기 홈페이지**입니다(클래스업·랠리즈·ACA2000·에드펜 등).
학원 목록 사이트가 이기는 학원 검색과 달리, 이 업종은 아이로그 페이지 자체로 노려볼 수 있는 자리라는 뜻입니다.
검색어별 1~10위 전체는 `경쟁-검색어-지면.md` 에 있습니다.

## 하지 않는 것

- 비교 글 운영사에 돈을 주고 순위를 사지 않습니다.
- 사용 후기·체험단 글을 만들어 뿌리지 않습니다. 대가가 있으면 표시광고법상 경제적 이해관계를 밝혀야 하고, AI 도 중복 글을 걸러냅니다.
- 없는 사용자 수·실적을 쓰지 않습니다. 지금 사이트에 없는 숫자는 파일 어디에도 넣지 않았습니다.
