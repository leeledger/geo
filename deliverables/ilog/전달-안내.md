## 올릴 파일

프로젝트가 Next.js App Router 입니다. 파일 위치가 곧 주소라 폴더만 맞추면 됩니다.

```
app/sitemap.ts      → /sitemap.xml 이 생깁니다
app/JsonLd.tsx      → 아래 한 줄을 layout 에 추가해야 동작합니다
public/llms.txt     → /llms.txt 로 그대로 열립니다
```

`app/layout.tsx` 의 `<body>` 안에 두 줄:

```tsx
import JsonLd from "./JsonLd";
// ...
<body>
  <JsonLd />
  {children}
</body>
```

## robots.txt 한 줄씩 추가 (선택)

지금은 `User-Agent: *` 로만 열려 있습니다. 동작에는 문제가 없지만,
AI 크롤러를 이름으로 적어 두면 의도가 분명해지고 진단 점수도 85 → 100 이 됩니다.
`/p/` 와 `/dashboard/` 차단은 그대로 두는 게 맞습니다.

```
User-agent: OAI-SearchBot
Allow: /
User-agent: ChatGPT-User
Allow: /
User-agent: GPTBot
Allow: /
User-agent: ClaudeBot
Allow: /
User-agent: Claude-SearchBot
Allow: /
User-agent: PerplexityBot
Allow: /
User-agent: Google-Extended
Allow: /

Sitemap: https://ilog.ai.kr/sitemap.xml
```

JSON-LD 와 llms.txt 에 들어간 사실은 **전부 지금 홈페이지에 적혀 있는 것**입니다.
기능·가격·특허 출원번호·문의 주소까지 페이지에서 그대로 옮겼습니다.
